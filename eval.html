Question test bench

The clerk's only job is to ask. This page runs the clerk's real prompt, the same code the office uses, over sixteen invented memories, two questions each, and counts what comes back: how many are real questions, how many needed a second try, how many fell back to a hand-written question, and how many pick up a word from what was just written. Like the office, it runs entirely in this tab. Answers are sampled, so each run is a little different.
